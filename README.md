This repo showcases the exploratory analysis of breast cancer data. The steps involved are: <br>
1. Descriptive statistics of dataset
2. Preprocessing of dataset (removing nulls, duplicate rows)
3. Rectifying class imbalances
4. Dataset classification training on
   - Naive Bayes model
   - Decision Tree model (a tree file is attached here)
   - Neural Network model
6. Performance evaluation across models
7. Determining the best model and most important parameter
